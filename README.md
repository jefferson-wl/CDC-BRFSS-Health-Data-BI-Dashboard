# CDC BRFSS Health Data BI Dashboard

## Project Overview

This Business Intelligence project analyzes public health survey data from the CDC Behavioral Risk Factor Surveillance System (BRFSS). The project explores health-related indicators, including obesity, physical activity, nutrition, survey coverage, and population characteristics across the United States.

## Objectives

- Prepare and clean public health survey data for analysis.
- Explore health trends and population distributions.
- Build an interactive Tableau dashboard to communicate findings.
- Examine survey coverage and data reliability.

## Tools & Technologies

- Python
- Pandas
- Tableau
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization

## Data Preparation

Python and Pandas were used to inspect and prepare the dataset, handle missing values, and remove redundant attributes before visualization and analysis.

## Dashboard

The Tableau dashboard presents visualizations of health survey coverage, health indicators, population distributions, and data reliability.

## Key Insights

- Obesity showed a consistent upward trend during the period analyzed.
- Physical activity estimates varied across survey categories.
- Smaller sample sizes were associated with greater uncertainty in estimates.

## Project Structure

The repository will contain the analysis notebook, dashboard screenshots, and dataset documentation.

CDC Behavioral Risk Factor Surveillance System (BRFSS).
